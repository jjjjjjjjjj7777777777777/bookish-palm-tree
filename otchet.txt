Используемые библиотеки:

pygame — библиотека для создания игр и графических интерфейсов на Python. Используется для отображения графики, обработки событий и анимаций.

Основные компоненты кода:

Инициализация:

Создание окна с размером 600x600 пикселей.

Настройка цветов для интерфейса (белый, черный, серый, красный).

Загрузка изображений крота и фоновой поляны.

Глобальные переменные:

GRID_SIZE — размер сетки 3x3 ячейки.

score_target — целевое количество очков для победы (10).

time_limit — лимит времени на игру (30 секунд).

current_row, current_col — текущая позиция крота.

Функции:

draw_grid() — отрисовка сетки игрового поля.

draw_target() — отображение крота в указанной ячейке.

restart_game() — сброс всех игровых параметров для перезапуска.

Игровой процесс:

Крот случайно перемещается по ячейкам каждые 1.2 секунды.

Игрок кликает мышью по кроту для получения очка.

При клике мимо крота очки не начисляются.

Завершение игры:

Победа при достижении 10 очков.

Поражение при истечении 30 секунд.

Отображение полупрозрачного оверлея (зеленый — победа, красный — поражение).

Перезапуск игры по клавише R.

Чтобы изменить целевое количество очков для победы, нужно поменять значение переменной score_target.

Изменение:

Замените строку:

python
score_target = 10
На нужное вам значение, например:

python
score_target = 5   # для победы нужно 5 очков
или

python
score_target = 20  # для победы нужно 20 очков
Что автоматически изменится:

Игра закончится победой, когда игрок наберет указанное количество очков

Отображение счета в левом верхнем углу будет показывать, например, 5/5 или 7/20

Полный фрагмент измененного кода:

python
score = 0
score_target = 5  # изменено с 10 на 5
time_limit = 30
Дополнительно — изменение времени:

Если хотите также изменить лимит времени, поменяйте переменную time_limit:

python
time_limit = 15  # игра будет длиться 15 секунд вместо 30
